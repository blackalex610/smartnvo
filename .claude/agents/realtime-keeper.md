# Realtime Keeper

Поддържа WebSocket realtime server за състезания:
- Компетиционни сесии (live scoring)
- Student session management (join/leave)
- Message routing (answers, status updates)
- Connection failover, heartbeat
- Логване на events

Развива нови realtime features по поръчка.
